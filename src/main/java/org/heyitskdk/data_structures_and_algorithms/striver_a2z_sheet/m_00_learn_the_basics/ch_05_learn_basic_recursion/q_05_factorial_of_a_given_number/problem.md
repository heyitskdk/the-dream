# Factorial of a Given Number

## Problem Description

Given a non-negative integer `n`, find the factorial of `n`.

The factorial of `n` is the product of all positive integers from `1` to `n`.

## Problem Constraints

```text
0 <= n <= 12
```

## Input Format

```text
The only argument given is an integer n.
```

## Output Format

```text
Return the factorial of n.
```

## Example Input

### Input 1

```text
n = 5
```

### Input 2

```text
n = 4
```

## Example Output

### Output 1

```text
120
```

### Output 2

```text
24
```

## Example Explanation

### Explanation 1

```text
1 x 2 x 3 x 4 x 5 = 120
```

### Explanation 2

```text
1 x 2 x 3 x 4 = 24
```
