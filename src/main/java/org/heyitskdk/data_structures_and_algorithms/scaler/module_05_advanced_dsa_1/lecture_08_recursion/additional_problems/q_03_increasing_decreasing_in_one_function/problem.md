# Decreasing Increasing in One Function

## Problem Description

Print `N` numbers in decreasing order and then in increasing order.

You are given a positive number `N`.

Print the numbers from `N` to `1`, and then from `1` to `N`.

You are required to not use any loops.

Do not change the signature of the function `DecThenInc`.

**Note:** Print a new line after printing the output.

## Problem Constraints

```text
1 <= N <= 100
```

## Input Format

```text
The first line contains a single integer N.
```

## Output Format

```text
Print a single line containing numbers from N to 1 and then from 1 to N.
```

## Example Input

### Input 1

```text
N = 1
```

### Input 2

```text
N = 4
```

## Example Output

### Output 1

```text
1 1
```

### Output 2

```text
4 3 2 1 1 2 3 4
```
