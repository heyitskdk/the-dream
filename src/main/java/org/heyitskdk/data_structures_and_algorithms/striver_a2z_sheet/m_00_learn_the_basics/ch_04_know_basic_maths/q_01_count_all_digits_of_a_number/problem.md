# Count Digits in a Number

## Problem Description

Given a number `n`, return the count of digits in this number.

## Problem Constraints

```text
1 <= n <= 10^9
```

## Input Format

```text
The only argument given is an integer n.
```

## Output Format

```text
Return the count of digits in n.
```

## Example Input

### Input 1

```text
n = 1567
```

### Input 2

```text
n = 99999
```

## Example Output

### Output 1

```text
4
```

### Output 2

```text
5
```

## Example Explanation

### Explanation 1

```text
There are 4 digits in 1567, which are 1, 5, 6 and 7.
```

### Explanation 2

```text
Number of digits in 99999 is 5.
```
