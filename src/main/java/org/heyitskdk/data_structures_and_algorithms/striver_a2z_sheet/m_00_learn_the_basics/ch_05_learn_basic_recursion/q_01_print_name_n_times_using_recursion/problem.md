# Print GFG N Times

## Problem Description

Given a positive number `n`, print the string `"GFG"` exactly `n` times, separated by a single space.

## Problem Constraints

```text
1 <= n <= 10^3
```

## Input Format

```text
The only argument given is an integer n.
```

## Output Format

```text
Print the string "GFG" exactly n times, separated by a single space.
```

## Example Input

### Input 1

```text
n = 5
```

### Input 2

```text
n = 3
```

## Example Output

### Output 1

```text
GFG GFG GFG GFG GFG 
```

### Output 2

```text
GFG GFG GFG 
```
