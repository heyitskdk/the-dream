# Most Frequent in an Array

## Problem Description

You are given an integer array `arr[]`.

Return the element that occurs the maximum number of times in `arr[]`.

**Note:** If multiple such elements exist, return the maximum element among them.

## Problem Constraints

```text
1 <= arr.size() <= 10^5
-10^5 <= arr[i] <= 10^5
```

## Input Format

```text
The only argument given is an integer array arr[].
```

## Output Format

```text
Return the element which occurs maximum times in arr[].
If multiple such elements exist, return the maximum element among them.
```

## Example Input

### Input 1

```text
arr[] = [1, 2, 2, 2, 4, 1]
```

### Input 2

```text
arr[] = [1, -5, 8, 1]
```

### Input 3

```text
arr[] = [3, 0, 0, 3, 8]
```

## Example Output

### Output 1

```text
2
```

### Output 2

```text
1
```

### Output 3

```text
3
```

## Example Explanation

### Explanation 1

```text
2 is the most frequent element of this array with 3 occurrences.
```

### Explanation 2

```text
1 is the most frequent element of this array with 2 occurrences.
```

### Explanation 3

```text
0 and 3 are two most frequent elements of this array.
3 is the maximum one among them.
```
