# Sum of First N Numbers

## Problem Description

Given an integer `n`, compute the sum of all natural numbers from `1` to `n`, inclusive.

If `n` is `0`, the sum should be `0`.

## Problem Constraints

```text
0 <= n <= 10^4
```

## Input Format

```text
The only argument given is an integer n.
```

## Output Format

```text
Return the sum of all natural numbers from 1 to n.
```

## Example Input

### Input 1

```text
n = 6
```

### Input 2

```text
n = 4
```

### Input 3

```text
n = 0
```

## Example Output

### Output 1

```text
21
```

### Output 2

```text
10
```

### Output 3

```text
0
```

## Example Explanation

### Explanation 1

```text
The sum of natural numbers up to 6 is:
1 + 2 + 3 + 4 + 5 + 6 = 21
```

### Explanation 2

```text
The sum of natural numbers up to 4 is:
1 + 2 + 3 + 4 = 10
```

### Explanation 3

```text
Since n is 0, the sum is 0.
```
