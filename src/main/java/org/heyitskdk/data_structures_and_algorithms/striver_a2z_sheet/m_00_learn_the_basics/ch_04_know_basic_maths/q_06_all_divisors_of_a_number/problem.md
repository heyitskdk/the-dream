# All Divisors of a Number

## Problem Description

Given an integer `n`, return all the divisors of `n` in ascending order.

A divisor of `n` is a number that divides `n` completely without leaving any remainder.

## Problem Constraints

```text
1 <= n <= 10^9
```

## Input Format

```text
The only argument given is an integer n.
```

## Output Format

```text
Return all the divisors of n in ascending order.
```

## Example Input

### Input 1

```text
n = 20
```

### Input 2

```text
n = 21191
```

## Example Output

### Output 1

```text
1 2 4 5 10 20
```

### Output 2

```text
1 21191
```

## Example Explanation

### Explanation 1

```text
20 is completely divisible by 1, 2, 4, 5, 10 and 20.
```

### Explanation 2

```text
21191 is a prime number, so it has only 2 factors: 1 and the number itself.
```
