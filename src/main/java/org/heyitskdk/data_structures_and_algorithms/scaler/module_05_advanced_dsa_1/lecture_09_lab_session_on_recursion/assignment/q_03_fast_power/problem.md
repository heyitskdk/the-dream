# Fast Power

## Problem Description

Given two positive integers `A` and `B`, implement the Fast Power function to compute `A^B`.

**Note:** Please use the approach taught in the class.

## Problem Constraints

```text
A^B would fit in 64-bit type integer.
```

## Input Format

```text
Two integers A and B.
```

## Output Format

```text
Return a single integer denoting the answer to A^B.
```

## Example Input

### Input 1

```text
A = 2
B = 10
```

### Input 2

```text
A = 1
B = 100000000
```

## Example Output

### Output 1

```text
1024
```

### Output 2

```text
1
```

## Example Explanation

### Explanation 1

```text
2^10 = 2^5 * 2^5
2^5 = 32, so 32 * 32 = 1024
```

### Explanation 2

```text
1 raised to power anything is 1.
```
