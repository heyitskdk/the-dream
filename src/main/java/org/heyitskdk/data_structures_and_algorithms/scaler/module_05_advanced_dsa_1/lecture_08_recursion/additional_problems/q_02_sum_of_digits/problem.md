# Sum of Digits!

## Problem Description

Given a number `A`, find the sum of its digits using recursion.

## Problem Constraints

```text
1 <= A <= 10^9
```

## Input Format

```text
The first and only argument is an integer A.
```

## Output Format

```text
Return an integer denoting the sum of digits of the number A.
```

## Example Input

### Input 1

```text
A = 46
```

### Input 2

```text
A = 11
```

## Example Output

### Output 1

```text
10
```

### Output 2

```text
2
```

## Example Explanation

### Explanation 1

```text
Sum of digits of 46 = 4 + 6 = 10
```

### Explanation 2

```text
Sum of digits of 11 = 1 + 1 = 2
```
